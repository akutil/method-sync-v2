# Сценарій відео (1–2 хв)

Записує й озвучує власник: курс просить «покажи продукт і розкажи, як ти будував його агентно». Приклад — поля
(`/fapi/v1/fundingRate`). У кадрі не має бути назв компанії і її внутрішніх систем; шляхи терпимі.

## Перед записом

```bash
git -C .sandbox/binancefutures checkout -- .
```

Прогін з агентом триває близько 50 с (e2e 2026-09-30: 48 с) — у відео його вирізати або прискорити.

   падає.» Показати в `registry.toml` блок `/fapi/v1/fundingRate`.
2. **Сухий прогін** (15 с, команда йде ~11 с):
   `PYTHONPATH=src python3 -m method_sync --registry registry.toml --only /fapi/v1/fundingRate --dry-run`
   → `перевірка=red`; у `runs/fapi-v1-fundingRate/report.md` рядок «бракує в моделі: markPrice, rateType».
3. **Цикл з агентом** (25 с, прогін вирізати):
   той самий запуск без `--dry-run` → `ітерацій=2  перевірка=green`;
   `git -C .sandbox/binancefutures diff` — два поля, гетери, сетери, `toString`. «Комітить людина, не інструмент.»
