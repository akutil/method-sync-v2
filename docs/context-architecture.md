# Context Architecture — method-sync-v2

> Статичний контекст оплачується на КОЖНОМУ ході агента; динамічний — лише коли задача його
> торкається. Межа між ними — архітектурне рішення, записане в ADR-0002.

## Статичний шар — щоходу (тримати малим)

Бюджет: **≤ 4k токенів.**

- `CLAUDE.md` → `@AGENTS.md`: межі (секрети, стейдж, коміти), конвенції модулів Python, правила,
  вивчені на помилках v1, каденція перевірок, test-first, протокол передачі, уроки фабрики.
- Не входить: принципи конституції повністю, факти research, специфікації, стандарт стилю бібліотеки.

## Динамічний шар — на вимогу

| Коли | Джерело |
|---|---|
| правка поведінки інструмента | `openspec/specs/<capability>/spec.md` + відповідний `src/method_sync/<module>.py` |
| рішення про принцип або межу | `docs/constitution.md` |
| твердження про біржу, Jackson, бібліотеку | `docs/research.md` (і нова проба, якщо факту там нема) |
| правка в цільовій бібліотеці | її власний скіл `add-binance-rest-endpoint` — агент бачить його, запущений у корені бібліотеки; текст скіла в промпт не вклеюється |
| рецензія правки в бібліотеці | `.claude/agents/method-sync-reviewer.md` |
| продовження роботи | `docs/current-state.md` (читається, не вбудовується) |
| QA / реліз | `docs/qa/`, звіти traceability / trajectory |

Динамічний контекст для кодуючого агента збирається під конкретний прогін: бриф із фікстурою цього
прогону, розходженням, виводом попередньої перевірки і рівно однією дозволеною командою
(`src/method_sync/agent.py`).

## Правила

1. **За замовчуванням — динамічний.** У статичний шар правило йде, лише якщо потрібне на більшості
   ходів і не виводиться з коду чи спеки перед очима.
2. **Правило додається, коли агент помилився двічі** (домовленість v1).
3. **Бюджет — не побажання.** Переріс — виносимо в спеку чи доку, а не піднімаємо бюджет мовчки.
4. **Версіоновано.** Зміна межі — новий ADR.

## Поточний стан

- **Бюджет:** 4k токенів. **Сьогодні:** ~3.6k (оцінка 2026-09-29: ~2.4k кириличних символів / 2.2 +
  ~9.4k інших / 3.8; половина — шість уроків фабрики англійською).
- **Винесено в динамічний шар одразу:** принципи конституції, факти research, стандарт стилю бібліотеки.
- **ADR:** `docs/adr/ADR-0002-context-architecture.md`.
